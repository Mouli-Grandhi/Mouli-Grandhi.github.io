Fall 2025CMPEH 472

Infrared remote-control robot

Final project, built with Michael Zimmerman

A two-wheel robot on a Raspberry Pi Pico W running MicroPython. An infrared remote steers it, yellow LEDs blink as turn signals, red LEDs flash in reverse, and an ultrasonic sensor stops it 10 cm short of an obstacle until you back up.

The motors could not turn reliably across most of the PWM range, so variable speed was out. We used PWM to balance the two motors instead, which made the robot drive straight.

  • Raspberry Pi Pico W
  • MicroPython
  • NEC infrared
  • HC-SR04
  • PWM motor control

Robot code and full report on GitHub

Enigma machine simulator

Solo project, two versions

A working copy of the WWII Enigma I cipher machine. Each letter passes through three rotors with the historical wirings, bounces off a reflector, and comes back through, and the rotors step before every key press. Feed the scrambled text back in from the same start position and the original message comes out.

  • Python
  • JavaScript
  • Code.org App Lab
